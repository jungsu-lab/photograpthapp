# FrameFit 완료 점검표

갱신일: 2026-07-17

이 문서는 구현 여부와 직접 검증 증거를 구분한다. `구현됨`은 코드에
존재한다는 뜻이고, `직접 확인`은 실제 Android 기기 또는 에뮬레이터에서
해당 흐름을 실행했다는 뜻이다.

| --- | --- | --- |
| 시스템 사진 선택과 실제 사진 표시 | 직접 확인 | Android 16 에뮬레이터에서 시스템 Photo Picker로 PNG를 선택해 편집기로 열었다. |
| 실제 픽셀 프리셋·강도·수동 보정 | 구현됨, 일부 직접 확인 | `PhotoProcessor`의 isolate 렌더링과 픽셀 테스트, Galaxy S23 기록이 있다. |
| 원본 비교·초기화·실행 취소/다시 실행 | 구현됨 | 편집기 위젯 테스트와 `EditHistory` 테스트가 있다. |

| 시스템 공유 | 직접 확인 | 에뮬레이터에서 시스템 공유 창과 생성 파일 미리보기를 확인했다. |

## 최신 검증 증거

- ASCII 전용 검증 작업공간에서 `flutter analyze`가 오류 없이 통과했다.
- 같은 환경에서 자동 테스트 50개가 모두 통과했다. 화면 비교 테스트는
  Windows 기준 이미지와 같은 Flutter 3.41.4 환경에서 분리하고, Linux
  CI는 기능 테스트와 Android APK 빌드를 수행하도록 고정했다.
- Android 16 에뮬레이터에 최신 x64 APK를 재설치해 `도쿄 네온` 선택 →
  실제 사진 선택 → 편집기 적용 → 홈 복귀 → 최근 프리셋 즉시 표시를
  직접 확인했다.
- GitHub Actions 실행 #3은 Linux Android 분석·기능 테스트·디버그 APK
  빌드와 Windows 화면 비교 테스트를 모두 성공으로 마쳤다.
- 최신 ARM64 릴리스 APK는 APK Signature Scheme v2 서명을 통과했다.
  `FrameFit-arm64-release-20260717.apk`의 SHA-256은
  `B79353A65F1AC302FA9BD85A67EB99D2F13BD9A3627F8A3EBB13E8CFF9410867`이다.

## 완료 전 남은 직접 검증

- 최신 코드로 실제 Android 카메라의 전·후면 촬영, 권한 거부·영구 거부,
  앱 백그라운드 복귀를 재확인한다.
- 세로 EXIF JPEG, 투명 PNG, 잘못된 파일, 저장 실패 및 대상 앱 수신을
  실제 기기에서 확인한다.
- iPhone 실기기에서 사진 선택·카메라·저장·공유를 확인한다.
- GitHub Actions에서 분리된 Linux 기능/빌드 작업과 Windows 화면 비교
  작업이 모두 통과하는지 확인한다.

따라서 현재 상태를 **실사용 Android MVP에 가까운 구현 상태**로 보되,
위 직접 검증 항목까지 끝나기 전에는 모든 플랫폼에서 최종 완료라고
표현하지 않는다.
