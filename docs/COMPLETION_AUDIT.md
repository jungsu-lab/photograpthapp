# FrameFit 완료 점검표

갱신일: 2026-07-17

이 문서는 구현 여부와 직접 검증 증거를 구분한다. `구현됨`은 코드에
존재한다는 뜻이고, `직접 확인`은 실제 Android 기기 또는 에뮬레이터에서
해당 흐름을 실행했다는 뜻이다.

| 실제 픽셀 프리셋·강도·수동 보정 | 구현됨, 일부 직접 확인 | `PhotoProcessor`의 isolate 렌더링과 픽셀 테스트, Galaxy S23 기록이 있다. |

## 최신 검증 증거

- ASCII 전용 검증 작업공간에서 `flutter analyze`가 오류 없이 통과했다.
- 같은 환경에서 자동 테스트 54개가 모두 통과했다. 화면 비교 테스트는
  Windows 기준 이미지와 같은 Flutter 3.41.4 환경에서 분리하고, Linux
  CI는 기능 테스트와 Android APK 빌드를 수행하도록 고정했다.
- Android 16 에뮬레이터에 최신 x64 APK를 재설치해 `도쿄 네온` 선택 →
  실제 사진 선택 → 편집기 적용 → 홈 복귀 → 최근 프리셋 즉시 표시를
  직접 확인했다.
- GitHub Actions 실행 #13(커밋 `c7147c2`)은 최신 코드를 대상으로 Linux
  Android 분석·기능 테스트·디버그 APK 빌드와 Windows 화면 비교 테스트를 모두
  성공으로 마쳤다.
- 최신 ARM64 릴리스 APK는 APK Signature Scheme v2 서명을 통과했다.
  `FrameFit-arm64-permission-release-20260717.apk`의 SHA-256은
  `B81600B38C4C862117D681C69342AF8E79473FC928A8735A9381CEF33E094EE6`이다.
- 최신 x64 APK의 깨끗한 설치에서 카메라 권한을 거부했을 때
  `카메라 권한이 필요해요`와 `다시 시도`가 직접 표시되는 것을 확인했다.
- 최신 x64 APK에서 카메라 권한 허용 → 빠른 촬영 → 실제 JPEG 촬영 →
  `자연 보정` 적용 → 원본 해상도 JPEG 생성 → 사진첩 저장을 완주했다.
  결과 파일 `FrameFit-CAP1602257483228859603-20260717095727358313.jpg`가
  Android MediaStore의 `Pictures/FrameFit/`에 생성된 것을 확인했다.
- iOS 프로젝트는 Swift Package Manager 플러그인 구조, iOS 13 배포 대상,
  카메라·사진·저장·동작 센서 사용 사유 문구를 자동 테스트로 확인했다.
  iOS 빌드와 실기기 실행은 macOS 환경에서 별도로 검증해야 한다.

## 완료 범위와 후속 검증

2026-07-17 제품 소유자 지시에 따라 이 인수 범위는 **Android MVP**로
한정한다. GitHub 저장소 공개 범위 변경과 iPhone 실기기 검증은 별도 후속
작업이며, 이 앱의 Android 기능 완료 판정에는 포함하지 않는다.

- Android 실제 기기 기록은 [DEVICE_TEST_CHECKLIST.md](DEVICE_TEST_CHECKLIST.md)에
  남아 있으며, Galaxy S23에서 PNG·12MP JPEG·전/후면 카메라·프리셋·원본
  해상도 내보내기·사진첩 저장·시스템 공유를 확인했다.
- Android 에뮬레이터에서는 권한 허용/거부, 실제 카메라 촬영부터 프리셋 적용과
  MediaStore 저장까지 최신 코드로 재검증했다.
- 세로 EXIF JPEG, 투명 PNG, 손상·지원하지 않는 입력, 저장·공유 실패는 실제
  픽셀·서비스 자동 테스트로 보호한다. 더 많은 물리 기기와 수신 앱에서의
  회귀 검증은 후속 릴리스 점검으로 유지한다.
- iPhone 준비·실기기 확인 항목은 [IOS_TEST_CHECKLIST.md](IOS_TEST_CHECKLIST.md)에
  보존한다.

따라서 현재 상태는 **검증된 Android MVP 완료**이며, iOS와 추가 기기 매트릭스는
명시적으로 후속 범위다.
