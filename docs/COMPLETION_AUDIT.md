# FrameFit 완료 점검표

갱신일: 2026-07-17

이 문서는 구현 여부와 직접 검증 증거를 구분한다. `구현됨`은 코드에
존재한다는 뜻이고, `직접 확인`은 실제 Android 기기 또는 에뮬레이터에서
해당 흐름을 실행했다는 뜻이다.

| 핵심 요구 | 상태 | 근거 |
| --- | --- | --- |
| 시스템 사진 선택과 실제 사진 표시 | 직접 확인 | Android 16 에뮬레이터에서 시스템 Photo Picker로 PNG를 선택해 편집기로 열었다. |
| 실제 픽셀 프리셋·강도·수동 보정 | 구현됨, 일부 직접 확인 | `PhotoProcessor`의 isolate 렌더링과 픽셀 테스트, Galaxy S23 기록이 있다. |
| 원본 비교·초기화·실행 취소/다시 실행 | 구현됨 | 편집기 위젯 테스트와 `EditHistory` 테스트가 있다. |

| 시스템 공유 | 직접 확인 | 에뮬레이터에서 시스템 공유 창과 생성 파일 미리보기를 확인했다. |

| 로컬 처리·메타데이터 보호 | 구현됨, Android 권한 직접 확인 | 출시 매니페스트에 인터넷 권한이 없고, Android 16 깨끗한 설치에서 카메라 외 사진/저장소 권한이 없음을 확인했다. JPEG 내보내기는 EXIF/XMP/IPTC/comment를 제거한다. |
| 오류 처리와 임시 파일 정리 | 구현됨 | 입력 검증, 권한·카메라 오류 안내, 실패 전달 테스트, 화면 이탈 시 임시 파일 정리가 구현되어 있다. |

## 최신 검증 증거

- `flutter analyze`는 카메라 초기화 경쟁 상태 보완 뒤 통과했다.
- 자동 테스트 47개는 임시 파일 정리 보완 뒤 통과했다. 이후 Android
  권한 매니페스트와 카메라 경쟁 상태 변경은 각각 실제 Gradle 병합
  결과와 정적 점검으로 확인했다. 이 Windows 환경에서는 뒤이은 Flutter
  테스트 컴파일이 반복적으로 지연되어, 이를 최신 전체 테스트 통과로
  표현하지 않는다.
- 최신 ARM64 릴리스 APK는 APK Signature Scheme v2 서명을 통과했다.
  SHA-256은 `0858EF16D33EDE1836AA8F7D2A313A14CC3F86F3EA754883792B6906565ECBF6`이다.

## 완료 전 남은 직접 검증

- 최신 코드로 실제 Android 카메라의 전·후면 촬영, 권한 거부·영구 거부,
  앱 백그라운드 복귀를 재확인한다.
- 세로 EXIF JPEG, 투명 PNG, 잘못된 파일, 저장 실패 및 대상 앱 수신을
  실제 기기에서 확인한다.
- iPhone 실기기에서 사진 선택·카메라·저장·공유를 확인한다.
- Windows Flutter 테스트 컴파일 지연을 분리한 뒤 최신 전체 자동 테스트를
  다시 실행한다.

따라서 현재 상태를 **실사용 Android MVP에 가까운 구현 상태**로 보되,
위 직접 검증 항목까지 끝나기 전에는 모든 플랫폼에서 최종 완료라고
표현하지 않는다.
