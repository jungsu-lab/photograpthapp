# FrameFit example-image manifest

## Privacy and provenance

- Every person shown in these examples is a single fictional adult woman in
  her mid-20s, created for FrameFit. She is not a customer, staff member, or
  public figure.
- The identity reference and neutral source fixtures live under `tool_assets/`.
  They are build tooling only and are not declared as Flutter assets.
- Production composition cards are compact, metadata-free JPEGs in
  `assets/images/composition/`. They contain no text, brands, or user data.
- Preset cards in `assets/images/preset-previews/` are generated by
  `dart run tool/render_preset_previews.dart` with `PhotoProcessor`, the same
  pixel processor used by the editor. They are not CSS or widget colour
  simulations.

## Fixed identity and visual direction

The reference subject uses shoulder-length softly waved dark-brown hair, a
cream knit top, dark denim, and restrained styling. Prompts require realistic
smartphone editorial photography: natural skin texture, ordinary imperfect
background detail, practical lighting, and no beauty-filter look.

Each id maps one-to-one to `assets/images/composition/<id>.jpg` in
`composition_catalog.dart`. This makes the card's composition demonstrable
instead of reusing one unrelated stock-like image.

## Rebuild steps

1. Create or approve a new fictional identity reference in `tool_assets/`.
2. Generate one natural 4:5 scene per composition id, inspect it for identity
   consistency, anatomy, text, brand marks, and whether the intended framing
   is visible.
3. Place accepted PNGs temporarily under `assets/images/composition/` and run
   `dart run tool/optimize_composition_assets.dart` to create 720px JPEGs.
4. Run `dart run tool/render_preset_previews.dart` after a recipe, source, or
   default intensity changes.
5. Run `flutter test test/visual_asset_catalog_test.dart` and inspect the
   preset-library and shooting-library screens on an emulator.

Do not use customer photos, add location metadata, or claim an image-based
feature that the app does not actually perform.
