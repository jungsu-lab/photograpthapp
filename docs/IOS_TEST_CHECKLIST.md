# FrameFit iOS 실기기 검증 체크리스트

이 체크리스트는 macOS와 실제 iPhone에서만 수행한다. 테스트 사진, 화면 캡처,
기기 식별자, 파일 경로는 저장소에 커밋하지 않는다.

## 사전 조건

- Xcode의 최신 안정 버전으로 Runner를 열고 실제 iPhone을 선택한다.
- 앱 식별자와 서명 팀을 설정한 뒤 Debug 빌드를 설치한다.
- 처음 설치하기 전 FrameFit의 카메라·사진 권한을 초기화한다.
- JPEG, PNG, 세로 EXIF JPEG, 투명 PNG, 12MP 이상 JPEG를 준비한다.
- `Info.plist`에 카메라, 사진 선택, 사진 저장, 동작 센서 설명이 모두 있는지
  확인한다. 이 저장소의 자동 테스트가 기본 설정을 보호한다.

## 핵심 완주 흐름

- [ ] 앱 실행 뒤 `사진 불러오기`를 탭하고 iOS 사진 선택기에서 JPEG를 고른다.
- [ ] 실제 사진이 편집기에 열리고 프리셋을 바꿀 때 미리보기가 갱신된다.
- [ ] 강도 0은 원본과 같고, 강도 100과 고급 보정이 결과에 반영된다.
- [ ] 길게 눌러 원본 비교, 실행 취소/다시 실행, 초기화를 확인한다.
- [ ] 원본 해상도 JPEG를 만들고 `사진첩에 저장`으로 저장한다.
- [ ] Photos 앱에서 FrameFit 결과를 열고, `다른 앱으로 공유`로 시스템 공유 창을
  열어 수신 앱에서 결과가 보이는지 확인한다.
- [ ] PNG 입력은 투명도를 유지해 PNG로 저장되는지 확인한다.

## 카메라와 구도 가이드

- [ ] 사용자가 `카메라로 촬영`을 탭했을 때만 카메라 권한을 요청한다.
- [ ] 권한 허용 후 전면·후면 카메라 모두에서 촬영하고 편집기로 이동한다.
- [ ] 권한 거부 시 재시도 안내, 영구 거부 시 설정 이동 안내가 표시된다.
- [ ] 구도 템플릿을 선택한 뒤 오버레이와 수평 안내가 보이고, 템플릿이 권장하는
  전·후면 카메라 및 플래시 상태가 적용되는지 확인한다.
- [ ] 앱을 백그라운드로 보냈다가 돌아온 뒤 카메라가 중복 초기화되거나 멈추지
  않는지 확인한다.

## 개인정보·오류·성능

- [ ] 저장 결과에 GPS 위치정보가 남지 않는지 확인한다.
- [ ] 사진 선택 취소, 손상 파일, 저장 공간 부족(가능한 경우)에서 앱이 종료되지
  않고 이해 가능한 오류를 보여 주는지 확인한다.
- [ ] 12MP JPEG에서 프리셋 미리보기와 원본 해상도 내보내기에 걸린 시간을 기록한다.
- [ ] VoiceOver에서 홈·촬영·편집·저장 핵심 버튼의 이름과 선택 상태가 읽히는지
  확인한다.
